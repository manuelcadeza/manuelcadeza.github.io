Política de privacidad

Última actualización: 2 de noviembre de 2026

Hermes es una aplicación de uso personal. Su único usuario es su propio desarrollador, que la usa con su propia cuenta de Google.

Qué datos se usan

Con autorización expresa mediante OAuth, Hermes puede leer y gestionar datos de la cuenta de Google del usuario: correos y borradores de Gmail, eventos de Calendar, archivos de Drive, Docs y Sheets, contactos, y cursos, tareas y avisos de Google Classroom (solo lectura).

Para qué se usan

Únicamente para atender solicitudes del propio usuario: buscar y resumir correos, preparar borradores, consultar su calendario y sus tareas escolares, y organizar sus pendientes.

Almacenamiento y seguridad

Las credenciales de acceso se guardan solo en la computadora del usuario, en un archivo protegido. Hermes no tiene servidores propios ni bases de datos externas. Para procesar una solicitud, el contenido necesario se envía al proveedor del modelo de inteligencia artificial que usa el asistente, únicamente para generar la respuesta.

Compartición

Los datos de Google no se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos de IA. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions, lo que invalida de inmediato las credenciales guardadas.
